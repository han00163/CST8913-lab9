# Future Growth and Budget Plan



## 1. Growth Assumptions: 

| Driver                                   | Assumption                    | Reason                                                   |
| ---------------------------------------- | ----------------------------- | -------------------------------------------------------- |
| Customer traffic (web, API, CDN, logs)   | **+25% per year**             | eCommerce growth across NA, EU and APAC                  |
| Primary SQL database (orders, customers) | **+20% per year**             | Order volume grows slightly slower than browsing traffic |
| Analytics NoSQL (Cosmos DB events)       | **+25% per year** without TTL | Event volume follows traffic                             |
| Data warehouse (15 TB)                   | **+20% per year**             | Keeps full history                                       |
| ML training hours                        | **+30% per year**             | More models and more frequent retraining                 |
| Payment VMs                              | **+10% per year**             | Scales with checkout peaks; hardened base stays small    |
| Security tooling                         | **+5% per year**              | Mostly fixed per region                                  |
| Storage, backup & DR                     | **+30% per year**             | Accumulating data and retention                          |
